== Description ==

Brnews Composer Pro is a powerful and flexible page builder plugin for WordPress, specially designed for news and magazine websites. With its intuitive drag-and-drop interface, you can create beautiful and responsive layouts without any coding knowledge.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/brnews-composer-pro` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress
3. Use the Composer menu in your WordPress admin to start building pages
