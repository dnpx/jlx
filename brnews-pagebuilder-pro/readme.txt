Um construtor de páginas visual completo e de alta performance, construído com a tecnologia nativa do WordPress, projetado para portais de notícias e criadores de conteúdo exigentes.

== Description ==
O Brnews Pagebuilder PRO (BRPB) é a solução definitiva para criar layouts complexos e dinâmicos diretamente no WordPress, sem a necessidade de frameworks externos ou processos de compilação. Construído com PHP, jQuery e a API AJAX do WordPress, ele oferece uma experiência de edição visual intuitiva, rápida e totalmente integrada ao seu painel.

Arraste e solte a partir de uma vasta biblioteca de elementos, incluindo grades de posts, blocos de monetização, elementos de cabeçalho e muito mais. Veja suas alterações em tempo real em um canvas que reflete exatamente a aparência do seu site.

== Installation ==
1) Faça upload do ZIP em Plugins → Adicionar novo → Enviar plugin.
2) Ative.
3) Edite uma página e clique em "Abrir Editor Visual".
